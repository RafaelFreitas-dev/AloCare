# ESSE PROJETO É UM DESENVOLVIMENTO DE CONCLUSÃO DO 4 SEMESTRE DO CURSO DE DESENVOLVIMENTO DE SOFTWARE MULTIPLATAFORMA DA FATEC ZONA SUL "DOM PAULO EVARISTO ARNS".
A IDEIA É CRIAR UM SISTEMA PARECIDO COM O GETNINJA, 99pilas NICHADO EM AREAS QUE ATENDEM OS CLIENTES RESIDENCIAIS E PROFISSIONAIS COMO ELETRICISTAS, PEDREIROS, FAXINEIRAS, DIARISTAS ETC...

O fluxo seria:

1. Cliente solicita serviço
2. Prestador envia proposta
3. Cliente aceita proposta
4. Cliente paga na plataforma
5. Dinheiro fica retido (escrow)
6. Prestador executa o serviço
7. Cliente aprova conclusão
8. Plataforma libera saldo
9. Prestador solicita saque
10. Plataforma transfere para conta bancária/Pix
